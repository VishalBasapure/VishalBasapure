## Featured projects

### 🛡️ InsiderShield — Real-Time Insider Threat Detection
Simulated Kafka → Spark pipeline modeling an enterprise-scale detection system, with a 7-day-ahead breach-risk model and K-Means clustering to surface anomalous users. Gemini turns every flagged alert into a plain-English narrative instead of a wall of logs, and every alert exports as an audit-ready PDF.

`Python` `Kafka` `Spark` `Streamlit` `Gemini API`

[![Live Demo](https://img.shields.io/badge/Live_Demo-24243e?style=for-the-badge&logo=streamlit&logoColor=FF4B4B)](https://insider-threat-detection-vishalbasapure.streamlit.app)

<br>

### 🚨 Crime Risk Analysis — Karnataka Crime Prediction System
End-to-end ML pipeline on 4 years of NCRB Karnataka crime data across 38 districts. Random Forest Regressor hitting R² = 0.877, built on 12 engineered features that fixed a nasty NCRB data-publication artifact (the model went from negative R² to 0.877 once that was resolved). Includes a 0–100 District Crime Vulnerability Index and a coverage-gap analysis across 921 police stations for resource planning.

`Python` `scikit-learn` `Streamlit` `GIS`

[![Live Demo](https://img.shields.io/badge/Live_Demo-24243e?style=for-the-badge&logo=streamlit&logoColor=FF4B4B)](https://crime-risk-analysis.streamlit.app)
[![Repo](https://img.shields.io/badge/Source-24243e?style=for-the-badge&logo=github&logoColor=white)](https://github.com/VishalBasapure/Crime-Risk-Analysis)

<br>
